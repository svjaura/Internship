# Internship
Internship outreach + tracker

The system lives in [`outreach/`](outreach/): a SQLite tracker, Gmail drafting and scheduled sending,
a review page, and Claude Code slash commands (`/status`, `/prospect`, `/draft`, `/review`, `/send`,
`/followup`, `/replies`, `/prep`, `/debrief`). Start with [`outreach/SETUP.md`](outreach/SETUP.md),
then read [`outreach/CLAUDE.md`](outreach/CLAUDE.md).

This repo is public. Prospect data, the database, credentials and personal details stay out of git
(see `outreach/.gitignore`).
